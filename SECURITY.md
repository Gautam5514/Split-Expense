# Security policy

## Supported versions

Security fixes are applied to the latest code on the `main` branch. The project
does not currently support older release lines.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/Gautam5514/Split-Expense/security/advisories/new).
Do not open a public issue for a vulnerability and do not include secrets,
personal data, or exploit details in a public discussion.

Include the affected component, steps to reproduce, impact, and any suggested
mitigation. A maintainer will acknowledge the report within 7 days, provide a
status update at least every 14 days, and coordinate disclosure after a fix is
available. Confirmed medium-or-higher severity vulnerabilities are prioritized
for remediation within 60 days; critical vulnerabilities are handled as soon
as practical.

## Disclosure and credit

Please allow time for investigation and a coordinated release before public
disclosure. Reporters may request public credit or remain anonymous.
